      Category effect sizes

      The model selects a category from −4 to +4, not a numerical delta. Set the state-unit change each category produces before the per-state multiplier. Zero normally means no change; changing its value adds a bias to those predictions.

      Example: category +1 mapped to +1.00 with a 2× multiplier adds +2.00 after baseline recovery. Settings apply next turn and remain when resetting the session.

      Per-state dynamics

      Applied each turn: recover toward the active baseline target → model category → category effect size → per-state multiplier → add and clamp. Slider changes take effect on the next turn. Reset session keeps these settings.
